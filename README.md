# Escaping the AI Herd: Executive Playbooks for Preventing Algorithmic Monoculture

**Companion code and practical exercises for _Escaping the AI Herd: Executive Playbooks for Preventing Algorithmic Monoculture_.**

**Book author:** Rowan Sterling

## About the book

This book provides senior executives and organizational leaders with practical, leadership-focused frameworks and real-world case studies for identifying, assessing, and mitigating the risks of algorithmic monoculture in enterprise AI adoption. It addresses how widespread reliance on similar AI models or decision systems can create systemic vulnerabilities, stifle innovation, and expose organizations to competitive and operational threats. The content emphasizes strategic governance, risk management, and actionable decision-making guidance tailored to the executive level, offering tools to safeguard organizational resilience and maintain a competitive edge in rapidly evolving AI landscapes.

## Who this is for

Senior executives and organizational leaders responsible for AI strategy and risk management in large enterprises or rapidly scaling organizations.

## What you will find here

This repository accompanies the book with chapter-specific implementation projects, examples, and reproducible exercises. Each implementation folder has its own README with the setup and execution instructions relevant to that chapter.

The book provides the explanations and context; this repository provides the companion implementation material.
